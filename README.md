 

# Scenario 1: BBC Sounds Podcast Recommendation System 

## Scenario 

The BBC wants to increase engagement with its BBC Sounds platform. Users often struggle to discover new podcasts, music programmes and radio shows they might enjoy. The BBC commissions a team to develop a prototype recommendation system. 

Real-Life Problem 

People repeatedly listen to the same content and miss programmes they would enjoy. 
 
## Features 

  Search programmes 

  Rate programmes 

  Recommend similar content 

  Display favourite genres 

  Generate listening reports 

## Python Prototype 

  SQLite database 

  Tkinter GUI 
  
  Pandas analysis 

## Team Roles 

Project Manager 

Database Developer 

Recommendation Engine Developer 

GUI & Testing Lead
